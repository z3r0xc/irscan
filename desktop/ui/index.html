A check for hidden monitoring software

This reads the logs, services, tasks and network connections of this machine and shows what is watching it.

It changes nothing: it only reads. Nothing on this step touches the disk, the registry or the network.

The check takes a few seconds. Its report can be saved to a file.

A clean result is not proof of a clean machine. No scan has been run yet, so nothing on this screen has been checked.
